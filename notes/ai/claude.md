# Claude

Claude is the family of large language models built by Anthropic. Claude is
trained using [[Constitutional AI]], a technique where the model critiques
and revises its own outputs against a set of written principles rather than
relying solely on human-labeled preference data.

Claude powers the Jarvis Assistant project in this notebook, and is the
model most of these notes were drafted and organized with. Its behavior is
heavily shaped by Prompt Engineering choices at the system-prompt level —
tone, caution, verbosity, and tool use all get tuned there.
